
# Assignment Submission Policy

Document ID: DOC-003
Last Updated: 2026-10-01
Data Status: SAMPLE ACADEMY DATA — NOT OFFICIAL

## 1. Assignment Instructions

Students must read the instructions provided with each assignment before starting their work.

An assignment may specify:
- Required tasks and learning objectives
- Accepted file formats
- Submission deadline
- Evaluation criteria
- Required references or documentation
- Whether resubmission is allowed

Assignment-specific instructions take precedence over general formatting examples when they explicitly define a requirement.

## 2. Submission Format

Unless an assignment specifies otherwise, the sample academy accepts the following formats:

- PDF for written reports.
- IPYNB for Jupyter notebooks.
- PY for standalone Python scripts.
- ZIP for a project containing multiple required files.

Students should use clear file names that include the assignment name and their student identifier.

Example:
student123_python_assignment.ipynb

Before submission, students should verify that:
- The file opens correctly.
- Required sections and outputs are included.
- The submitted file belongs to the correct assignment.
- No unnecessary temporary files or credentials are included.

For notebook assignments, students should ensure that the notebook contains the required code and explanations.

## 3. Submission Procedure

Students should submit assignments through the designated academy learning platform.

A submission is considered recorded only when the platform confirms that the file was received.

Students should keep the submission confirmation for their records.

If the platform fails during submission, students should capture the error message and contact technical support.

A screenshot of an attempted upload is useful evidence but does not independently prove that the academy received the assignment.

## 4. Late Submissions

Under this fictional academy's default sample policy, assignments submitted after the stated deadline are marked late.

A deduction of 10% of the assignment's maximum available points is applied for each started 24-hour period after the deadline, up to a maximum deduction of 30%.

Example:
An assignment is worth 100 points and is submitted 26 hours late.

Two 24-hour periods have started, so the deduction is 20 points.

The score before any other grading adjustments is reduced by 20 points.

This example describes the sample policy only. A specific assignment may define a different late-submission rule.

## 5. Extensions

Students who need an extension should contact the instructor or designated academy support team before the deadline whenever possible.

An extension request should include:
- Assignment name
- Original deadline
- Requested new deadline
- Brief explanation of the request

Submitting a request does not automatically grant an extension.

Students should rely on an explicitly confirmed extension rather than assuming that the deadline has changed.

## 6. Resubmission Policy

For this sample academy, resubmission is permitted only when the assignment instructions or instructor explicitly allow it.

If resubmission is allowed, students must follow the stated resubmission deadline and file-format requirements.

Students should not assume that replacing an uploaded file automatically changes the graded submission.

## 7. Plagiarism and Academic Integrity

Students must submit work that reflects their own understanding and must acknowledge sources they use.

Copying another student's work and submitting it as one's own is prohibited under this sample policy.

Students must follow the assignment's rules regarding collaboration and AI-assisted tools.

If AI assistance is permitted, students should follow the stated disclosure requirements and verify the accuracy of generated material.

The use of an AI tool is not automatically permitted or prohibited for every assignment; the applicable instructions must be checked.

Suspected academic-integrity violations should be reviewed through the academy's designated process before any conclusion is reached.

## 8. Grading and Feedback

Each assignment should provide grading criteria or a rubric when applicable.

Students should review instructor feedback to understand mistakes and areas for improvement.

If a grade appears inconsistent with the published rubric, students may contact the instructor and identify the relevant grading criterion.

The academy support team should not invent a grade or change a grade without authorized records.

## Document Notes

All submission rules, late penalties, and academic-integrity procedures in this document are fictional sample academy data. They are not official rules of any real educational institution.
