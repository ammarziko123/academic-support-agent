## 1. Python Programming Fundamentals

Course Level: Beginner
Duration: 6 weeks
Prerequisites: Basic computer skills
Session Frequency: Two sessions per week

### Topics Covered
- Variables, data types, and operators
- Conditional statements and loops
- Functions and modules
- Lists, tuples, dictionaries, and sets
- File handling and exception handling
- Introduction to object-oriented programming

### Expected Learning Outcomes
By the end of this course, students should be able to:
- Write basic Python programs.
- Use loops and conditions to solve problems.
- Create reusable functions.
- Work with common Python data structures.
- Handle basic file operations and errors.

## 2. Machine Learning Fundamentals

Course Level: Intermediate
Duration: 8 weeks
Prerequisites: Python fundamentals and basic statistics
Session Frequency: Two sessions per week

### Topics Covered
- Data preprocessing and exploratory data analysis
- Feature engineering and feature selection
- Supervised and unsupervised learning
- Linear regression and logistic regression
- Decision trees and k-nearest neighbors
- Model evaluation and cross-validation
- Overfitting, underfitting, and regularization

### Expected Learning Outcomes
By the end of this course, students should be able to:
- Prepare datasets for machine learning.
- Train basic classification and regression models.
- Select suitable evaluation metrics.
- Identify common overfitting problems.
- Build a small end-to-end machine learning project.

## 3. Deep Learning and Computer Vision

Course Level: Advanced
Duration: 10 weeks
Prerequisites: Python, machine learning fundamentals, and basic linear algebra
Session Frequency: Two sessions per week

### Topics Covered
- Neural networks and backpropagation
- Activation functions and loss functions
- Optimizers and regularization
- Convolutional neural networks
- Transfer learning
- Image classification
- Introduction to image segmentation

### Expected Learning Outcomes
By the end of this course, students should be able to:
- Explain the basic structure of neural networks.
- Train a simple deep learning model.
- Apply transfer learning to image datasets.
- Evaluate image classification models.
- Develop a basic computer vision project.
