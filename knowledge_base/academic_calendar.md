## 5. Deadline Interpretation

A deadline is considered passed when the current academy-local time is later than the recorded deadline.

The agent should distinguish between:
- A deadline date and its exact time.
- A scheduled presentation date and an assignment deadline.
- A known calendar entry and an unknown assignment name.

If the requested assignment does not appear in the calendar, the agent must report that no matching deadline was found.

The agent must not calculate or invent a substitute deadline for an unknown assignment.

## 6. Calendar Maintenance

Calendar changes should be made by an authorized maintainer.

When a deadline changes, the calendar should be updated and its last-updated date revised.

The agent should use the current calendar data rather than treating an earlier conversational statement as an authoritative source.

## Document Notes

Every date, course schedule, deadline, and presentation time in this document is fictional sample academy data. These dates are intended only for software development and evaluation, not for real student planning.
